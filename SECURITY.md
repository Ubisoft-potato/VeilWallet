# Security policy

This repository is a development preview. It has not undergone an independent security audit and has not been validated for production funds. The detailed security model and known limitations are in [Documentation/SECURITY.md](Documentation/SECURITY.md).

Do not post private keys, seed phrases, wallet passwords, privacy notes, signed transaction payloads, account screenshots or exploitable vulnerability details in public issues, pull requests or logs.

Once the GitHub repository is published and private vulnerability reporting is enabled, use **Security → Report a vulnerability**. No public repository or private reporting destination is configured in this source preparation yet. Until one is available, do not submit sensitive reports through public channels.

For a private report, provide the affected version, a minimal reproduction using disposable public fixtures, impact and a suggested fix if available. Never include real funds or live credentials. There is currently no guaranteed response time or funded bounty program.

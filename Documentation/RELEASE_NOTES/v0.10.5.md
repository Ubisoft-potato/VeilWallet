# Veil Wallet v0.10.5

First public development preview for macOS 14+ on Apple Silicon. Built by GitHub Actions and distributed through GitHub Releases.

## Included

- Pin Swift build/test architecture to match the thin native crypto archive, including cloud Release builds.

- Split DEX view expressions for reliable compilation with the pinned cloud Swift compiler; transaction guards and approval continuation are preserved.

- Native SwiftUI/AppKit wallet with local key storage and app-scoped bundled Tor networking.
- Supported multichain accounts, portfolio prices, transfers, transaction management and configured EVM/TRON interactions. Availability varies by protocol; unsupported operations remain labeled in the application.
- English and Simplified Chinese with immediate language switching.
- Numbered mnemonic import boxes: 12/24 words, additional BIP39 lengths, full-phrase paste, keyboard navigation and local spelling/checksum validation.
- Explicit corresponding-source deliveries, third-party notices, LGPL replacement/relink evidence and SHA256 checksums.

## Download and install

Download VeilWallet-0.10.5-macOS-arm64.dmg and SHA256SUMS from this release. Verify the DMG's SHA256, open it and drag Veil Wallet.app to Applications.

The installer is ad-hoc signed and **not Apple notarized**. If macOS blocks opening it, verify the downloaded file, then use System Settings > Privacy & Security to allow that application. Do not disable Gatekeeper globally.

This wallet has not received an independent security audit or complete live-funds acceptance. It is a development preview, not a production-readiness certification or a guarantee of anonymity. Published source test vectors must never hold funds. Preserve recovery material and complete privacy-pool notes offline; a mnemonic cannot reconstruct a random note.

Source archives, BUILD-INFO.json, MANIFEST.json, SOURCE-INVENTORY.json and verification reports accompany the installer. See Documentation/RELINKING.md in the application source archive for modification and rebuild instructions. Component licenses remain separate from the original application's MIT license.

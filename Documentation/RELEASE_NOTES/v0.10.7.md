# Veil Wallet v0.10.7

Development preview for macOS 14+ on Apple Silicon. Version tags trigger the GitHub Actions DMG build and verified prerelease publication; ordinary main-branch pushes do not trigger the installer build.

## Changes

- Group reviewed instances of the same asset across networks into one collapsed row, with combined integer-precision balances and USD values. Expand the whole row to see each network's address, contract and actions. Wrapped, legacy, bridged and unknown same-ticker assets retain their separate identities.
- Show network price ranges and partial/historical data indicators. Keep expansion state during balance updates and live English/Simplified Chinese switching.
- Simulate EVM contract calls using the approved gas limit before signing, with bounded gas-budget retries during preparation. Reject paused Balancer pools before quoting.
- Add explicit TRON Nile identities and SunSwap V2 testnet deployments, plus isolated Sepolia/BSC Testnet Stargate routes. Mainnet and testnet routes cannot mix.
- Add opt-in protocol execution tools and documented public-testnet/fork acceptance evidence. Generated test credentials and reports remain in the ignored build directory.

## Validation and remaining limits

Local regression passed 152 Swift tests in 31 suites, plus native asset-group click/language checks, localization checks and source-content scanning. Public tests are opt-in and are not silently rerun by the ordinary suite.

Public Sepolia Uniswap V2/V3/V4 round trips and a Nile SunSwap V2 round trip were confirmed. ETH/BSC venue and privacy-pool execution evidence uses isolated forks or local chains. These results do not establish mainnet readiness for every catalog entry.

The Sepolia-to-BSC Testnet Stargate source transaction confirmed, but destination delivery remains unverified. Source success alone is not a completed bridge. Mainnet SUN smart routing and TRON-source bridge execution remain outside the completed funded execution scope. See [protocol acceptance](https://github.com/Ubisoft-potato/VeilWallet/blob/v0.10.7/Documentation/PROTOCOL_ACCEPTANCE.md).

iCloud Keychain synchronization is disabled. The current legacy macOS Keychain implementation does not provide a verified device-binding or Migration Assistant exclusion guarantee. Wallet files and Keychain material may be transferred by system migration. This release documents that limitation; it does not change existing vault/key storage.

## Download and install

Download `VeilWallet-0.10.7-macOS-arm64.dmg` and `SHA256SUMS` from this release. Verify the DMG checksum, open it and drag `Veil Wallet.app` to Applications.

The installer is ad-hoc signed and **not Apple notarized**. If macOS blocks opening it, verify the downloaded file, then use System Settings > Privacy & Security to allow that application. Do not disable Gatekeeper globally.

This wallet has not received an independent security audit or complete live-funds acceptance. Published source fixtures must never hold funds. Preserve recovery material and complete privacy-pool notes offline; a mnemonic cannot reconstruct a random note.

Exact source deliveries, third-party notices, LGPL replacement/relink evidence and SHA256 checksums accompany the installer. Component licenses remain separate from the original application's MIT license.
